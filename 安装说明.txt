AgentMeter — macOS 菜单栏 Code Agent 用量监控
================================================

【安装】
1. 双击打开 .dmg 文件
2. 将 AgentMeter 图标拖入右侧的「Applications（应用程序）」文件夹
3. 从启动台或应用程序文件夹打开 AgentMeter，菜单栏会出现仪表盘小图标

【首次打开提示“无法验证开发者”？】
本应用未经过 Apple 公证（个人分发常见），首次打开选择以下任一方式：
· 方法一：打开 系统设置 → 隐私与安全性 → 安全性，点击「仍要打开」
· 方法二：终端执行   xattr -cr "/Applications/AgentMeter.app"   后正常打开

【支持的用量数据源】
· GLM 编码套餐   —— 填编码套餐 API Key（菜单栏图标 → 设置 → 数据源）
· DeepSeek       —— 填开放平台 API Key，显示现金余额
· Kimi           —— 编码订阅 key（sk-kimi-…）显示 5小时/7天用量；开放平台 key 显示余额
· Codex          —— 无需配置，自动读取本机会话与 ChatGPT 实时用量
· Claude Code    —— 无需配置，自动扫描本机会话文件

【功能】
· 用量窗口进度条 + 重置倒计时
· 阈值系统通知提醒（60% / 70% / 80% / 90% 可多选）
· 自动刷新间隔 5/10/30/60 分钟，支持开机自启
· API Key 仅保存在本机钥匙串，不会上传
